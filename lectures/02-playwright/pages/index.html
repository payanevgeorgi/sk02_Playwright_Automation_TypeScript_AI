Form & Field.Lecture 2 / Advanced interactions

The next layer

A little more interaction.

Independent, local examples for practicing advanced Playwright interactions. No sign-in, server, or internet connection required.

01 / Dropdowns

Select by value, label, or index, and choose multiple countries.

02 / Checkboxes & radio buttons

Toggle preferences, select an experience level, and validate a registration.

03 / Tables & selectors

Find rows by text or position, extract cells, and edit a member's role.

04 / File uploads

Select, replace, and clear single or multiple files.

05 / Dynamic content

Observe loading, newly inserted elements, and a delayed enabled button.

06 / Iframes

Interact with a separate document using a frame locator.

07 / Browser dialogs

Accept or dismiss native alerts, confirmations, and prompts.

Each example starts fresh when reloaded. Use demo data only; nothing is sent to a server.
